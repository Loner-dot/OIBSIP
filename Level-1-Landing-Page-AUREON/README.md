# AUREON | Landing Page

A responsive landing page for AUREON, a fictional independent digital studio. Created as the Level 1 Landing Page task for the Oasis Infobyte Web Development and Designing internship.

## Features

- Responsive layout for mobile, tablet and desktop
- Sticky navigation with an accessible mobile menu
- Hero section with custom CSS-built visual artwork
- Approach, capabilities, principles and contact sections
- Semantic HTML and accessible navigation labels
- Reduced-motion support
- Vanilla JavaScript, no frameworks required

## Built with

- HTML5
- CSS3
- Vanilla JavaScript

## Run locally

Open `index.html` in a browser. No build tools or package installation are required.
