# DAYMARK | Daily Planner

DAYMARK is a mobile-first personal planning dashboard built as a bonus portfolio project. It focuses on clear task management, daily progress and intentional focus sessions.

## Features
- Create, edit and delete tasks
- Set due dates, categories and priority levels
- Mark tasks complete and clear completed entries
- Filter by today, upcoming, all tasks and completed tasks
- Search tasks by title or category
- Daily progress ring and task statistics
- 25-minute focus timer with pause, resume and reset
- Local browser storage so tasks remain after refresh
- Responsive desktop and mobile layouts
- Keyboard focus states and reduced-motion support

## Built with
- Semantic HTML5
- CSS3
- Vanilla JavaScript
- Browser localStorage API

## Run locally
Open `index.html` in a modern browser. No dependencies, build tools or installation are required.

## Data and privacy
Tasks are stored in the current browser on the current device. They are not uploaded to a server. Clearing the browser's site data will remove saved tasks.
