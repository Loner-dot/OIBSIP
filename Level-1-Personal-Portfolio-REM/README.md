# REM | Personal Developer Portfolio

A responsive personal portfolio built for the Oasis Infobyte Web Development and Design Level 1 programme.

## Design direction
A dark, atmospheric glass interface with restrained cyan lighting, layered translucent surfaces, editorial typography and custom CSS project artwork. The layout is designed mobile-first and adapts for larger screens without relying on a component framework or template.

## Built with
- HTML5
- CSS3
- Vanilla JavaScript

## Included
- Introductory hero and developer profile
- About section and current learning toolkit
- Selected project showcases with live links
- Direct email and Telegram contact
- Responsive navigation with keyboard and Escape-key support
- Reduced-motion support and visible keyboard focus
- Responsive layouts for phone, tablet and desktop
