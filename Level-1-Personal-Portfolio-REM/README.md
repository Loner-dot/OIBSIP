# REM | Personal Developer Portfolio

A responsive personal portfolio created for the Oasis Infobyte Web Development and Design Level 1 task.

## Built with
- HTML5
- CSS3
- Vanilla JavaScript

## Features
- Responsive, mobile-first layout
- About, skills, selected projects and contact sections
- Accessible mobile navigation with keyboard support
- Direct email and Telegram contact links
- Reduced-motion preference support

## Run locally
Open `index.html` in a browser. No build tools or dependencies are required.
